# Changelog

All notable changes to this project will be documented in this file.

## 0.1.3 - 2026.01.04

- Added output_activation/output_mask support in generate_ltspice_subckt and export_model_to_ltspice.
- Added output_activation support in build_model_from_sequential.
- Modified siggen.py to include filename text in generated LTspice symbol.

## 0.1.2 - 2025.12.29

- Added utilities: `siggen`, `modelgen`, and `sampling`.
- Moved developer tools from `tools/modelgen` to `tools/utils_test`.
- Updated example code to use the new utilities.

## 0.1.1 - 2025.12.28

- Renamed `Pytorch2LTspice.py` to `pytorch2ltspice.py`.

## 0.1.0 - 2025.12.14

- Initial release.
